  расчёт степеней, ожидаемые сценарии и вопросы до реализации.
- [Предложение о сопоставлении подграфов](subgraph-matching-proposal.md):
  поиск вне A/B, occurrenceId и отображения узлов; этот алгоритм не реализован.

Актуальное состояние — в [архитектуре](../architecture/overview.md),
