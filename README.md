# Relationer

Проект для построения генеалогических деревьев и поиска аналогичных родственных структур в справочнике.

## Статус MVP

- **День 9 функционально завершён.** Пользователь проверил локальную интеграцию frontend/backend: поиск работает ожидаемо. Подробности и история конкретных автоматических проверок — в [отчёте Дня 9](docs/day9-integration.md).
- **День 10 не завершён.** Остаются Docker, развёртывание, публикация и smoke-тест публичного сервиса. Локальная проверка Дня 9 не заменяет публичный релиз.
- [POST-MVP roadmap](docs/roadmap-post-mvp.md) начинается только после полноценного публичного релиза, включая завершение Дня 10.

## Запуск фронтенда

Нужны Node.js >= 22.12 (рекомендуется 22.22.0), npm и JDK 21 для генерации API-клиента. При первом запуске нужен доступ к Maven Central.

Из корня проекта:

```sh
cd frontend
# Если используется nvm:
nvm install
nvm use
npm ci
npm run dev
```

Если терминал использует Node.js 16, а локальная версия уже подготовлена в `frontend/.cache/node/bin`, из каталога `frontend` выполните:

```sh
export PATH="$PWD/.cache/node/bin:$PATH"
node -v # v22.22.0
npm run dev
```

В новом терминале версию нужно выбрать снова. При запуске из IDE укажите тот же Node interpreter: `frontend/.cache/node/bin/node`, либо Node.js 22 из nvm.

Откройте адрес, который выведет Vite. Для редактирования графа backend не требуется. Для поиска запустите в отдельном терминале из корня `cd backend && ./gradlew bootRun`: Vite проксирует `/api` на порт 8080. Выберите A/B через «Участники и результаты» и нажмите «Найти совпадения». [Настройка API и ручные сценарии](docs/day9-integration.md).

## Тесты фронтенда

В каталоге `frontend` после установки зависимостей:

```sh
npm test                 # Unit-тесты
npm run typecheck        # Проверка TypeScript
npm run test:e2e         # Браузерные тесты; нужен установленный Google Chrome
```

Браузерные тесты сами запускают сервер на порту 4173. Вместо Google Chrome можно установить Chromium:

```sh
npx playwright install chromium
PLAYWRIGHT_CHANNEL=chromium npm run test:e2e
```
