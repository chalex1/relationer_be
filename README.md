# Relationer

Relationer позволяет построить граф родства, выбрать двух людей A/B и найти
похожие пути в справочнике исторических случаев. Вердикты берутся из эталонов;
приложение не вычисляет универсальное разрешение или запрет брака.

**День 11 завершён.** День 12 открыт: подключён единый каталог MVP, публичный релиз впереди.
Техническая часть Docker-развёртывания завершена ранее; публичный релиз ещё
не подтверждён. Статусы и следующие задачи — в [едином roadmap](docs/roadmap.md).

## Возможности

- Конструктор `/`: биологические, брачные, духовные и приёмные связи, выбор A/B,
  редактирование людей и связей, масштабирование и поиск совпадений.
- Публичный каталог `/references`: 11 рабочих и 94 черновых записи, 94 уникальных
  кейса в поиске; поиск по ID, названию, описанию и источникам, сортировка и фильтры.
- Раскрытая вертикальная лента с подгрузкой графов порциями по 10.
- Компактные графы с иерархической раскладкой ветвей, выделением A/B и разворотом.
- Цветные вердикты, категории, описания, страницы и заключения источников.
- 94 оригинальных PNG и JSON хранятся на backend, выдаются через API.
- Статус проверки графа отделён от исторических выводов источников.
- Локальное ревью черновиков, комментарии, импорт/экспорт результатов и повторная
  проверка после изменения содержимого. Отметки не записываются в серверный JSON.

Черновик конструктора хранится только в памяти и теряется при перезагрузке
или переходе на другую страницу. Загрузки эталона в конструктор, авторизации,
БД и редактирования каталога через UI нет.

## Быстрый старт без Docker

Нужны JDK 21, Node.js >= 22.12 и npm. Проверенная локальная версия Node —
22.22.0 (`frontend/.nvmrc`). Первый запуск Gradle и генератора API требует доступа
к репозиториям зависимостей. Запускайте команды из корня проекта в двух терминалах.

Терминал 1 — backend:

```sh
cd backend
./gradlew bootRun
```

Терминал 2 — frontend:

```sh
cd frontend
# Если установлен nvm, перед npm выберите версию проекта:
# nvm install
# nvm use
npm ci
npm run dev -- --port 5173 --strictPort
```

Откройте [конструктор](http://127.0.0.1:5173/) или
[каталог эталонов](http://127.0.0.1:5173/references).
Vite проксирует `/api` на `http://127.0.0.1:8080`. Для каталога и поиска нужны
оба процесса; для редактирования графа backend не обязателен. Остановка —
`Ctrl+C` в соответствующем терминале.

Если в этой рабочей копии уже подготовлен Node в `frontend/.cache/node/bin`,
вместо nvm можно выбрать его из каталога `frontend`:

```sh
export PATH="$PWD/.cache/node/bin:$PATH"
node -v
```

Этот путь не поставляется с репозиторием, а `export` действует только в текущем
терминале. Для IDE также выберите Node >= 22.12.

## Docker и проверки

Запуск через Docker Compose, готовые образы, Caddy и HTTPS описаны в
[руководстве развёртывания](docs/deployment.md). Команды тестов и генерации
клиента — в [frontend README](frontend/README.md).

Backend из каталога `backend`:

```sh
./gradlew test openApiValidate
```

Frontend из каталога `frontend`:

```sh
npm test
npm run typecheck
npm run build
npm run test:e2e
```

Playwright использует Chrome и сам запускает Vite на порту 4173. Для проверок
с реальным backend требуется отдельно запущенный Spring Boot и
`RUN_BACKEND_INTEGRATION=1`.
